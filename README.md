# Servidor Programación Avanzada

API básica desarrollada con ASP.NET Core para realizar prácticas
de arquitectura cliente-servidor en la asignatura Programación Avanzada.

## Endpoints

### Principal
GET /

### Saludo
GET /api/saludo

### Estado de vehículo
GET /api/vehiculo

### Evaluar temperatura
GET /api/temperatura/{valor}

Ejemplo:

GET /api/temperatura/105
